## 2. Instruksi Pendaftaran Karakter Baru (Untuk Admin)

Ketika pemain baru mendaftarkan karakter atau meminta pendaftaran official save:
1. Buat file baru di folder `players/` dengan nama `<Nama_Karakter>.md`.
2. Gunakan template di bawah ini.
3. Tambahkan entri karakter ke tabel di atas pada file `players.md` ini.
